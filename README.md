# E-commerce Sales Analytics Dashboard

## Project Overview

This project analyzes e-commerce sales data using Microsoft Excel to understand revenue performance, customer behavior, regional performance, product categories, payment methods, and order outcomes.

The project includes data cleaning, Pivot Table analysis, Key Performance Indicator (KPI) calculations, and an interactive sales dashboard.

## Dashboard Preview

![E-commerce Sales Dashboard](Ecommerce_Sales_Dashboard.png)

## Key Performance Indicators (KPIs)

| Metric | Result |
|---|---:|
| Total Revenue | ₹19,470 |
| Total Orders | 15 |
| Order Success Rate | 86.67% |
| Average Order Value (AOV) | ₹1,498 |
| Repeat Customer Rate | 25% |

Average Order Value (AOV) was calculated using successful orders because cancelled and returned orders were excluded from actual revenue.

## Data Cleaning

The dataset was prepared for analysis by:

- Removing duplicate records
- Handling missing values
- Standardizing inconsistent text and categories
- Checking discount values
- Separating successful, cancelled, and returned orders
- Creating calculated revenue fields
- Checking data consistency before analysis

## Analysis Performed

The project analyzes:

- Revenue by region
- Revenue by product category
- Payment method share
- Top customers by revenue
- Order success rate
- Average Order Value (AOV)
- Repeat customer rate
- Discounts and actual revenue

## Key Insights

- Total successful-order revenue was ₹19,470.
- 13 of 15 orders were successfully completed, producing an Order Success Rate of 86.67%.
- East generated the highest regional revenue at ₹6,155.
- Electronics generated the highest category revenue at ₹9,500.
- UPI represented the largest payment-method share.
- Rahul Sharma was the highest-revenue customer at ₹3,780.
- Average Order Value (AOV) for successful orders was approximately ₹1,498.
